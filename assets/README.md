# Visual identity assets

`emerald-online-3ds-icon-source.png` is the original high-resolution project mark. `emerald-online-3ds-icon.png` is its 48x48 SMDH derivative, and `emerald-online-3ds-banner.png` is the deterministic 256x128 HOME Menu banner composition.

The emblem was generated with OpenAI's built-in image generation tool using this prompt:

> Create an original 48x48-readable game-app icon: a bold faceted emerald whose four corners connect to four glowing network nodes. Use a deep forest-green background, emerald/mint highlights, and restrained gold accents. No text, Pokemon creatures, Pokeballs, official lettering, Nintendo or mGBA logos, character silhouettes, or watermark.

The banner reuses that original emblem with project-local typography. The CIA build consumes copies under `third_party/mgba/res/`.
