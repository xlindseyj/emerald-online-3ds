# Release media

Store only project-created release visuals here. Preferred assets are authentic emulator or physical-console captures of the Emerald Online 3DS interface and installation setup. Limited in-game screenshots may document a tested multiplayer workflow, but never publish ROMs, saves, extracted asset sheets, identities, recovery codes, console keys, or personal information.

Use lowercase versioned filenames such as `0.8.1-map-radar.png`, add the matching `/release-media/...` entry to `release/release-catalog.json`, and describe whether the capture came from Azahar or physical hardware. The catalog validator rejects remote tracking images and unsupported paths.
