# Release media

Store only project-owned release visuals here. Preferred assets are authentic emulator or physical-console captures of the original Emerald Online 3DS lower-screen UI and installation setup, cropped so no ROM-derived game pixels, private saves, identities, recovery codes, or personal information are published.

Use lowercase versioned filenames such as `0.8.1-map-radar.png`, add the matching `/release-media/...` entry to `release/release-catalog.json`, and describe whether the capture came from Azahar or physical hardware. The catalog validator rejects remote tracking images and unsupported paths.
